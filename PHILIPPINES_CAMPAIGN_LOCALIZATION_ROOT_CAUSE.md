# CrowdWisdom AI Studio — Philippines Campaign Localization Root-Cause Analysis

**Audit Date:** 2026-11-11  
**Target Environment:** Production & Local Workspace  
**Status:** Resolved & Verified  

---

## 1. Executive Summary

An investigation was conducted into the country-context contamination observed in Philippines (PH) marketing campaigns, specifically Campaign `6af40fdda1c92020dd501115` (`PSE Blue Chip & Dividend Alpha — Philippines 🇵🇭`) and Script `6af4151714e1e47fbd321144` (`The Noise Trap — NSE Blue Chip & Dividend Alpha — Philippines PH`).

The campaign displayed severe market contamination:
1. **Exchange Mismatch:** "NSE" (National Stock Exchange of India) appeared in the title of a campaign explicitly targeting the Philippines.
2. **Regulatory Mismatch:** Scene 04 on-screen text asserted `• SEBI Compliant Research` (Securities and Exchange Board of India).
3. **Narrative Decoupling:** Voiceovers contained generic, ungrounded lines (`"Market makers love retail chaos"`) rather than localized Philippine market context (PSEi, Philippine blue chips, social media chat room tips/chismis).
4. **Visual Subject Mismatch:** Scene 01 visual description specified a close-up macro shot of hands typing on a keyboard, but the generated visual was a portrait of a woman looking down.

This report provides the complete architectural trace of how the defect entered the pipeline and documents the permanent, multi-tiered structural fix.

## 2. Forensic Code Trace & Root Cause

### Root Cause 1: Parameter Omission in Fallback Domain Synthesizer Call
- **File:** `backend/agents/script_agent.py` (Line 496–498)
- **Flawed Code:**
  ```python
  # When LLM candidate generation failed or exceeded similarity limits:
  script_data = self._generate_fallback_script(..., target_country=target_country)
  _, script_data, _ = self._validate_and_normalize_script(
      script_data, approach, duration, campaign_config
  )  # <-- target_country was OMITTED!
  ```
- **Function Signature:**
  ```python
  def _validate_and_normalize_script(
      self, script_data, approach, duration, campaign_config, target_country: str = "IN"
  )
  ```
- **Effect:**
  Because `target_country` was omitted at line 497, it defaulted to `"IN"`.
  Inside `_validate_and_normalize_script`, the method called:
  `country_localization_service.localize_script_dict(normalized_script, "IN")`.

### Root Cause 2: Aggressive Cross-Exchange Rewriting in Localization Service
- **File:** `backend/services/market_intelligence/country_localization_service.py` (Line 248)
- **Flawed Code:**
  ```python
  if norm == "IN":
      result = re.sub(r'\bPSE\b', 'NSE', result)
  ```
- **Effect:**
  Because `norm` was defaulted to `"IN"`, the valid Philippine title generated by the domain synthesizer:
  `"The Noise Trap — PSE Blue Chip & Dividend Alpha — Philippines 🇵🇭"`
  was actively mutated into:
  `"The Noise Trap — NSE Blue Chip & Dividend Alpha — Philippines 🇵🇭"`.

### Root Cause 3: Regulatory Tag Auto-Injection
- **File:** `backend/services/market_intelligence/country_localization_service.py` (Lines 185–188)
- **Flawed Code:**
  ```python
  if norm == "IN" and "SEBI" not in ost:
      final_scene["on_screen_text"] = f"{ost} • SEBI Compliant Research"
  ```
- **Effect:**
  Because `norm` was `"IN"`, Scene 04 was automatically tagged with `• SEBI Compliant Research`.

### Root Cause 4: Research Context Leakage via Unfiltered Inheritance
- **File:** `backend/agents/script_agent.py` (Lines 358–368)
- **Flawed Code:**
  ```python
  if not campaign_ads:
      campaign_ads = await db.advertisements.find({"date_verification_status": "verified"}).limit(6)
  if not insights:
      insights = await db.marketing_insights.find({}).limit(10)
  ```
- **Effect:**
  When a new Philippines campaign had no direct prior ads scraped, it queried the global database without filtering on country. Indian advertisements (featuring Nifty, BankNifty, Zerodha, SEBI) were passed into the Script Agent LLM prompt.

### Root Cause 5: Gap in Consistency Validation Regex
- **File:** `backend/services/market_intelligence/country_localization_service.py` (Line 361)
- **Flawed Code:**
  ```python
  if norm == "PH" and ("₹" in val or re.search(r'\b(?:INR|rupees?|Nifty|Sensex|SEBI|Dalal Street)\b', val, re.I)):
  ```
- **Effect:**
  `NSE` and `BSE` were omitted from the regex. When the title contained `"NSE Blue Chip"`, `validate_script_country_consistency` returned `is_consistent: True` and failed to catch the error.

## 3. Implemented Architectural Fixes

| Component | Defect | Architectural Fix |
| :--- | :--- | :--- |
| `script_agent.py` | Line 497 omitted `target_country` | Explicitly passed `target_country=target_country` to `_validate_and_normalize_script`. |
| `script_agent.py` | `_validate_and_normalize_script` hardcoded `"IN"` default | Changed signature to `target_country: Optional[str] = None` and resolved hierarchically from argument -> `script_data` -> `campaign_config` -> `"IN"`. Never blindly defaults to `"IN"`. |
| `script_agent.py` | Cross-border research leakage in lines 358–368 | Added strict country filtering (`{"$or": [{"country": norm_country}, {"target_country": norm_country}]}`) for inherited ads and marketing insights. |
| `script_agent.py` | Archetype 3 had generic voiceovers | Replaced with grounded country-specific variants: Philippines references PSEi, retail social rumors ("chismis" vs volume), and Makati/BGC institutional capital. |
| `country_localization_service.py` | Regulatory claims of compliance | Replaced `"• SEBI Compliant Research"` and `"• SEC Philippines Compliance"` with educational disclaimers: `• For Educational & Market Sentiment Research Only (SEC Philippines Disclosures Apply)`. |
| `country_localization_service.py` | Missing terms in consistency regex | Added `NSE`, `BSE`, `Bank Nifty`, `FinNifty`, `Demat`, `Lakhs`, `Crores`, `Zerodha`, `Groww`, `AngelOne` to forbidden terms for Philippines; added `Makati`, `Ayala`, `Ortigas`, `Bonifacio`, `SEC Philippines` for India. |
